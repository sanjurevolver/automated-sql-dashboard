# Repository collaboration rules

- Make changes on a feature or fix branch and open a pull request.
- Never push directly to `main` or the default branch.
- Do not merge pull requests unless the user explicitly asks you to merge them.
- Do not force-push or rewrite shared branch history without explicit authorization.
- Keep raw data, generated reports, credentials, and local environments out of Git.
- Run relevant validation and report its actual results in the pull request.
